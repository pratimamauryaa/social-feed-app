# Social Feed App

A responsive Social Media Feed application built using React.js, Bootstrap, and DummyJSON API. This application allows users to view posts fetched from an external API, create new posts, delete posts, and explore a clean social feed interface.

## 🚀 Features

- Responsive User Interface
- Sidebar Navigation
- Home and Create Post Sections
- Fetch Posts from DummyJSON API
- Create New Posts
- Display Posts in Social Feed
- Delete Posts
- Post Reactions and Tags
- Loading Spinner
- Error Message Handling
- State Management using Context API and useReducer
- Mobile Responsive Design

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Bootstrap 5
- Vite
- REST API
- DummyJSON API

## 🌐 API Integration

This project uses the DummyJSON Posts API to fetch dummy social media posts.

**API Endpoint:**
https://dummyjson.com/posts

**Concepts Used:**

- Fetch API
- useEffect Hook
- JSON Data Handling
- API Integration
- Loading and Error Handling

The application is designed to provide a smooth experience on both desktop and mobile devices.
